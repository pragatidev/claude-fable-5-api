# Access setup

1. Create an Anthropic account and an API key at https://console.anthropic.com
2. Confirm the workspace is not on zero data retention. Fable 5 is a Covered Model. A ZDR org gets 400.
3. Copy `.env.example` to `.env` and paste the key. Never commit `.env`.
4. Run `python labs/01_first_call.py`

Claude.ai, Claude Code, Amazon Bedrock, Vertex AI, and Microsoft Foundry are valid doors.
This course records the Claude API path. Other doors are named, not labbed.

Mythos 5 (`claude-mythos-5`) is Project Glasswing only. There is no lab for it.
