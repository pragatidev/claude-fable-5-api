# Fable 5 and Mythos 5

One sentence: they share the same underlying weights. Fable 5 is the public twin with safety classifiers. Mythos 5 is the Glasswing twin without those classifiers.

| | Fable 5 | Mythos 5 |
|---|---|---|
| Model ID | `claude-fable-5` | `claude-mythos-5` |
| Who can call it | Generally available | Project Glasswing partners |
| Classifiers | Yes. Can return `stop_reason: "refusal"` | No |
| Price, context, output | Same | Same |
| This course | Default lab model | Named once, not a lab |

Do not tell a student they can buy Mythos 5.
